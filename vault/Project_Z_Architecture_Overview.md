# Project Z Architecture Overview

*Category: architecture | Tags: zaine, roadmap, ai, jarvis | Added: 2026-09-04*

---

Z.A.I.N.E is built as a unified offline Jarvis assistant running locally on RTX 2050 GPU. Core components: Ollama (Qwen2.5 / Zaine persona), Faster-Whisper, Piper TTS, Telegram Mobile Bridge, SQLite persistent memories, and Personal Vault RAG.
