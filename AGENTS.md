# PROJECT HISTORY LEDGER — MANDATORY

**Every AI, IDE, or automation that modifies this project MUST update `PROJECT_HISTORY.md`.**

- Read `PROJECT_HISTORY.md` at the START of your session to understand what has been done.
- APPEND an entry for every change you make BEFORE ending your session.
- NEVER delete or modify existing entries — it is an append-only immutable ledger.
- Each entry must include: date/time (ISO 8601), author (your model name + IDE/tool), type, scope, description, and commit hash.
- See the template at the top of `PROJECT_HISTORY.md` for the exact format.
